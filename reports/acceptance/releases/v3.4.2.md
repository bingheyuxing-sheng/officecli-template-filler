# v3.4.2 — 审阅安全性与诚实的 QA

- 版本：**v3.4.2**
- 发布日期：2026-11-01
- 发布类型：**正式版**
- 对应提交：`69f0c86`（附注 tag `v3.4.2`，归档提交；v3.4.2 源码提交为 `c47be7a`）

## 一句话

这个版本让审阅修改更安全：修订编号与文档里的真实编号一致，复杂结构不被拆坏，多处相同文字不会误改；同时给 QA 增加了“未验证”状态。

## 这个版本改变了什么

- **修订 ID 真实一致**：报告里的 `revision_ids` 直接记录真实分配值，和 DOCX 中的 `w:id` 严格一致，不再由计数器反推。
- **结构安全**：跟踪修订只在连续纯文本 Run 组内进行；超链接、内容控件、域容器位置不变；含绘图、域代码、脚注引用的 Run 拒绝拆分，降级为批注。
- **定位安全**：支持 `location_id` 精确寻址和 `occurrence` 指定第几处；多处匹配但未指定位置时拒绝自动修改，写入 `AMBIGUOUS_MULTIPLE_MATCHES` 批注。
- **表格合并**：`gridSpan` / `hMerge` / `vMerge` 不自动改写；恢复后仍有合并差异时状态为 `PARTIALLY_APPLIED`，并列出未处理属性。
- **Excel 宏**：`.xlsm` 使用 `keep_vba=True`、`keep_links=True` 加载，强制输出 `.xlsm`；Excel 检查改为对照原始模板，不再拿输出和自己比较。
- **Excel 公式**：内置评估器无法计算的公式计入 `unsupported_formulas` / `unverified_count`，产生 `FORMULAS_UNVERIFIED` 覆盖缺口；`SUBTOTAL` 按功能码分派。
- **QA 四态**：新增 `UNVERIFIED`；存在无法执行的检查时，整体状态不再报 `PASSED`。
