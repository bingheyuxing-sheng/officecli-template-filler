# v3.5.2 — Excel 可靠性、版面指纹、PROOFREAD 与合并安全写入

- 版本：**v3.5.2**
- 发布日期：2026-11-02
- 发布类型：**正式版**
- 对应提交：`b1358ea`（附注 tag `v3.5.2`）
- 说明：本版本包含 v3.5.0 的事务层和能力注册表。

## 一句话

这个版本完成 v3.5 计划的 M4–M9：让 Excel 公式和对象处理更可靠，增加版面指纹检查、进程身份、PROOFREAD 校对模式，以及更安全的合并单元格写入。

## 这个版本新增了什么

### Excel

- 公式平移改用 `openpyxl` 官方 `Translator`，字符串常量和跨表引用不再被正则误改。
- 结构化引用、外部工作簿、`INDIRECT` / `OFFSET` 明确返回 `UNSUPPORTED_*`，不做猜测性替换。
- 每个公式单元格新增 `formula_status`：`VERIFIED` / `FAILED` / `UNSUPPORTED` / `NOT_RECALCULATED`；后两类计入未验证。
- 新增 `engine/excel_objects.py`，扫描 VBA、ActiveX、Power Query、透视表、切片器、外部连接和图表。
- 存在无法保留的对象时，`generate_excel.py` 以 `OBJECT_LOSS_RISK`（退出码 3）拒绝生成，需要显式加 `--allow-object-loss`。

### 版面和进程

- 新增 `engine/layout_qa.py`，按页面、段落、表格、图片比较版面。
- 仅替换正文内容不会误报；字号 / 字体漂移报 `LAYOUT_FONT_DRIFT`，对齐 / 缩进漂移报 `LAYOUT_POSITION_DRIFT`，表格列宽比例差超过 5% 报 `LAYOUT_TABLE_DRIFT`。
- 进程身份改为 `(pid, image, creation_time)`；只终止能证明由本任务启动的实例，无法证明的候选记入 `unreleased_pids`。
- `taskkill` 不再带 `/T`；清理日志按任务拆分。

### 校对与表格

- 新增第 8 种模式 `PROOFREAD` 和 `scripts/proofread_document.py`，输出带修订的 `.docx` 和快照。
- 路由关键词覆盖“错别字 / 校对 / 数据错误 / 逻辑问题 / proofread / typo”，不再落入 REFORMAT。
- `restore_table_style_from_reference()` 返回 `{topology_ok, restored, skipped, manual_required}`；只在行列拓扑一致、合并区域至多一个非空文本、且不含修订 / 批注锚点时写入合并属性。
- 修复“模板 12pt 被写成 11pt”的长期偏差：段落格式轮廓优先采用 Run 的直接字号。

## 测试结果

- **101 项全部通过**。

## 已知限制

- 结构化引用、外部工作簿、`INDIRECT` / `OFFSET` 返回 `UNSUPPORTED_*`。
- 内置评估器无法计算的公式计为未验证。
- 复杂 Excel 对象（ActiveX、Power Query、透视表、切片器）无法保留。
- 合并属性只在安全条件下写入，否则降级为 `manual_required`。
