- 对应提交：`17d68f4`（附注 tag `v3.5.3`）

## 一句话

这个版本增加了 FAST / STANDARD / FULL 三档执行模式、培养方案模板语义预检、分阶段检查点，以及渲染和目录降级规则。

## 这个版本新增了什么

- **执行档位**：`GENERATE` / `EXCEL_GENERATE` 写入前统一选择 `FAST`、`STANDARD` 或 `FULL`；档位只改变处理范围，不降低包检查、SSOT 校验、事务提交和覆盖缺口披露要求。
- **模板语义预检**：培养方案任务在写入前检查培养层次、目录与正文标题、跨表课程名称 / 代码、学分学时、学期数、占位图 / 样例图及过期目录页码，并输出结构化修复计划。
- **课程 SSOT**：要求以单一 `curriculum_ssot` 派生毕业要求、课程矩阵、学分学时分配、学期小计和教学进程表，统一使用精确小数并在写入前完成跨表校验。
- **分阶段检查点**：`STANDARD` / `FULL` 按正文、表格、图片、目录依次保存并验证；失败时从最近的有效检查点恢复，禁止整篇无差别重做。
- **渲染与目录降级**：每阶段只允许一次有界渲染；失败后清理任务自有进程并降级到包 / OOXML / 版面指纹检查。无法刷新目录域时标记 `PENDING_FIELD_UPDATE`，估算页码必须标记 `ESTIMATED`。
- **审阅契约修正**：格式修复必须配套 `w:*PrChange`；不支持或结构不安全的修改进入批注或 `manual_required`。
