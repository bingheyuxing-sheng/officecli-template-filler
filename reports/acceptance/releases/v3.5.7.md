# v3.5.7 — REFORMAT 差异清单、带修订应用与 PDF 渲染

- 版本：**v3.5.7**
- 发布日期：2026-11-03
- 发布类型：**正式版**
- 对应提交：`097156b`（轻量 tag `v3.5.7`）
- 说明：本版本同时包含 v3.5.6 的路由与 QA 修复。

## 一句话

这个版本正式启用了 `REFORMAT` 模式：先列出“哪里和模板不一样”，再把能安全修复的地方写成 Word 格式修订，让人逐条接受或拒绝；同时补上了 WPS / LibreOffice 的 PDF 渲染和真实页数测量。

## 这个版本新增了什么

### REFORMAT 执行器

- 新增 `engine/reformat_engine.py` 和 `scripts/reformat_document.py`。
- `build_reformat_plan()` 按文本、标题、表题、首行、列几何等语义锚点对齐段落和表格，产出结构化差异清单。
- 每条差异包含 `current` / `reference_value` / `action` / `reason` / `confidence`。
- 差异分成四类：
  - `AUTO_FIX`：匹配且安全，可以自动修；
  - `REVIEW`：混合 Run、加粗变化、行数漂移，需要人看；
  - `KEEP`：新增段落 / 表格，不和模板硬比；
  - `UNSUPPORTED`：列数不一致等。
- `execute_reformat_plan()` 只应用 `AUTO_FIX`，每处变更写入 Word 原生格式修订（`w:rPrChange` / `w:pPrChange` / `w:tblPrChange` / `w:trPrChange` / `w:tcPrChange`）。
- plan-only 模式不写任何输出；apply 模式走事务，包检查通过但仍有待审项时状态为 `PENDING_HUMAN_REVIEW`。

### PDF 渲染与页数

- 新增 `engine/pdf_backend.py`：自动探测 WPS `kwpsconvert.exe word2pdf` 和 LibreOffice `soffice`。
- `OFFICECLI_PDF_BACKEND=wps|libreoffice|none` 可以强制指定后端。
- 转换在临时副本上进行，避免源文件被预览进程锁定。
- 页数优先用 PyMuPDF 读取；没有时用 WPS `pdfinfo` 读取真实页数。
- 视觉检查报告 `pdf_backend` / `page_count_source` / `page_count_available`；页数检查无法执行时记 `PDF_PAGE_COUNT_UNVERIFIED`。
- WPS 未登录或没有 VIP 时明确报 `WPS_VIP_REQUIRED`，不静默降级。

## 同时包含的 v3.5.6 修复

- `.docx` + `.xlsx` 不再无条件判为 `MERGE`：生成意图下 `.xlsx` 是数据源，主模式是 `GENERATE`；修改意图走 `REFORMAT`；显式合并意图才走 `MERGE`。
- 语义对齐：GENERATE 用 `STYLE_GUIDE`，REPAIR / REVIEW 用 `REPLICA`；新增内容标为 `NEW_CONTENT` / `NEW_TABLE`。
- 严重级门禁：只有 `high` 是硬失败，`medium` / `low` 进入警告。
- 字体名归一：黑体↔SimHei、仿宋↔FangSong、宋体↔SimSun、Courier↔Courier New。
- 文件锁报告占用 PID；清理脚本只终止指定 PID，不做全局强杀。

## 测试结果

- 全量：**126 项通过**。
- 新增 `test_p0_semantic_qa.py` 8 项、`test_reformat_and_pdf.py` 7 项。
- 实测培养方案样例：差异清单 37 条（29 字体、3 行数、2 表主导字号、1 加粗、1 单元格、1 新表），自动可修 2 条，其余进入 REVIEW / KEEP。
- WPS 转换成功，模板 43 页、成品 81 页，页数不一致检查可用。

## 已知限制

- REFORMAT 只自动应用 `AUTO_FIX`，其余需要人工确认。
- PDF 渲染依赖本机 WPS / LibreOffice；两者都没有时相关检查为 `UNVERIFIED`。
- 页数测量优先 PyMuPDF，缺失时依赖 WPS `pdfinfo`。
- `POLISH` / `MERGE` 仍不可用。
