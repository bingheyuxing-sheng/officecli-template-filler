# v3.5.8 — 内容真值与图片真值

- 版本：**v3.5.8**
- 发布日期：2026-11-04
- 发布类型：**正式版**
- 对应提交：`e39dd7c`（轻量 tag `v3.5.8`）

## 一句话

这个版本修复了两个“假成功”：图片看起来换了、实际没换；矢量图没检查、却也不报缺口。同时补上了正文和表格之间的内容一致性检查。

## 这个版本修复了什么

### 图片

- **SVG 双嵌入残留**：Word 2016+ 插入 SVG 时，会同时写一张栅格兜底图和一份 SVG 引用。旧逻辑只替换兜底图，SVG 引用还在，Word 仍显示旧图，但程序报告成功。现在替换时会移除 `svgBlip` 扩展，让兜底图成为唯一来源。
- **矢量图静默跳过**：SVG / EMF / WMF 以前既不报错也不报缺口。现在记入 `coverage_gaps: VECTOR_IMAGE_UNVERIFIED`，整体状态变为 `UNVERIFIED`。
- **VML 图片替换**：支持 WPS 页眉 logo、公章、老模板常用的 `w:pict` / `v:imagedata`；独占时原位替换，共享时新建部件并重绑 `r:id`。
- **引用计数补全**：同时统计 `a:blip`、`asvg:svgBlip`、`v:imagedata`，避免共享图被误判为独占。
- **裁剪框与显示框**：替换时清除旧裁剪框；可以按新图比例重算显示框，也可以保留原框。
- **外部链接图片**：`r:link` 不再静默跳过，会列出所属部件和目标，提示分发可能丢图。

### 内容

- 新增 `engine/consistency_qa.py`，`run_qa.py` 默认执行（`--no-content-qa` 关闭）：
  - `CONTENT_VALUE_CONFLICT`（high）：正文与表格对同一“总计类”标签给出不同数值。
  - `CONTENT_SUBTOTAL_MISMATCH`（high）：表尾合计行不等于上方各行之和（逐列精确小数比对）。
  - `CONTENT_LABEL_VALUE_VARIANCE`（medium）：同一非总计标签在正文 / 跨表出现少量不同值。
  - `CONTENT_TERM_DRIFT`（medium）：同一实体两种写法（张伟 / 张玮）。
  - `CONTENT_DATE_FORMAT_MIXED` / `CONTENT_UNIT_STYLE_MIXED`（low）：日期与金额单位写法混用。
- 报告返回 `label_values`（抽取出的 `label → value` 和位置），让“比了什么”可审计。
- `audit_fact_sources()`：事实缺少 `source` 报 `FACT_SOURCE_MISSING`（high）；`UNVERIFIED` / `MODEL_GENERATED` 计入未验证事实。
- `find_numeric_occurrences()`：PROOFREAD 输出同一数值的全部出现位置和上下文，作为人工判定证据。

## 测试结果

- 全量：**138 项通过**。
- 新增 `test_content_and_image_truth.py` 12 项。
- 实测：内容检查抽取 256 个 `label → value`，0 条误报；构造的合计错误（2504 vs 2400）和“正文 100 万 / 表格 105 万”都被高严重度捕获。

## 已知限制

- OCR 未集成，只做诚实降级（`OCR_UNAVAILABLE`）。
- 图表 / 占位图重绘仍只是编排要求，引擎只提供替换通道。
- 按角色定位图片尚未实现（v3.5.9 才加入）。
