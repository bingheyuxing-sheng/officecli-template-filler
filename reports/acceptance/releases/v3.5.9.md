# v3.5.9 — 图片角色、可选 OCR、流程闭环与编排辅助

- 版本：**v3.5.9**
- 发布日期：2026-11-04
- 发布类型：**正式版**
- 对应提交：`fed6f6b`（轻量 tag `v3.5.9`）

## 一句话

这个版本补齐了流程文档里“写了但引擎里没有落地”的关键环节：内部事实确认、审阅自动文字修订、校对自动检查、图片角色定位、可选 OCR、图表重绘，以及确认门、执行档位、检查点、目录判定、多轮视觉检查等编排辅助。

## 这个版本新增了什么

### 模板理解与确认

- 空白或占位的内部事实字段（负责人、联系电话、内部编号等）会被识别为 `internal_fact` 槽位，确认级别为 `MUST_ASK_USER`。
- `resolve_confirmation_gate()` 按“L4 / 阻断冲突 > 必须问用户 > 用户要求跳过 > 可选决策”的优先级返回确认档位。

### 审阅

- `build_review_plan(auto_text_diff=True)` 自动对齐模板与草稿，为相似度 ≥ 0.6 的同槽位段落生成文字修订。
- 自动跳过 `{{...}}` 占位符、红字模板残留、空白内部事实字段、SDT、域代码、超链接和图片段落。
- `review_document.py` 默认开启自动文字 diff，可用 `--no-auto-text-diff` 关闭。

### 校对

- 新增 `audit_proofread_candidates()` / `build_proofread_plan()`：
  - 复用内容真值检查：数值冲突、合计不符、名称漂移、日期 / 单位混用；
  - 新增保守错别字词表；
  - 新增重复标题检查；
  - 接入重复段落、空章节、编号跳号、日期区间倒挂等逻辑检查。
- 批注可以锚定正文段落、页眉页脚和表格单元格。
- `proofread_document.py` 默认开启自动检查，可用 `--no-auto-check` 关闭。

### 图片与图表

- `find_images(doc, role=...)` 支持 `logo` / `stamp` / `qr` / `illustration` / `photo`，每个结果给出判定证据。
- `replace_image_by_role()` 只替换唯一匹配项；匹配到 0 个或多个时列出候选位置并拒绝替换。
- 可选 OCR：依次探测 RapidOCR、PaddleOCR、Tesseract；无后端时返回 `OCR_UNAVAILABLE`，不谎报通过。
- `render_chart_image()` 支持表格、柱状图、饼图，200 dpi 输出 PNG；缺 matplotlib 或中文字体时返回明确状态。

### 编排与逻辑辅助

- `engine/workflow.py`：确认门、执行档位、检查点、目录判定与降级、多轮视觉检查。
- `engine/logic_qa.py`：重复段落、空章节、编号跳号、日期区间倒挂。
- `engine/research.py`：研究策略、查询计划、事实来源校验；实际联网检索仍由 Agent 执行。

## 这个版本修复了什么

- 修复 `find_images` 对页眉 / 页脚根节点漏检的问题。
- 包完整性新增 `w:proofErr` 配对检查，输出 `PACKAGE_PROOFERR_UNBALANCED`。
- 文件锁错误的 `lock_info` 增加 `cleanup_log`，指向当前任务的清理日志。
- 合计检查支持表头行，首行非数字时跳过表头，不再放弃整列。

## 已知限制

- `POLISH` / `MERGE` 仍无执行入口，路由返回 `CAPABILITY_NOT_AVAILABLE`。
- 逻辑检查是确定性启发式，不能判断论证是否成立或语义是否自洽。
- `research` 模块只负责策略、查询计划和来源校验，实际检索由 Agent 完成。
- 视觉检查依赖本机 PDF 后端；缺失时状态为 `UNVERIFIED`，像素级比对仍需 PyMuPDF。
- SVG / EMF / WMF 只能报告 `VECTOR_IMAGE_UNVERIFIED`。
- `L4` 对象（Chart / SmartArt / OLE / 宏）只读保留并列入 `coverage_gaps`。
- `workflow` 提供 API，不新增 `--profile` 等 CLI 参数。

## 安装

1. 下载 `officecli-template-filler-v3.5.9-review-docx.zip`。
2. 解压后把 `officecli-template-filler/` 放入 Agent 的 skills 目录。
3. 安装依赖：`python -m pip install -r requirements.txt`。

可选组件：PyMuPDF、WPS / LibreOffice、RapidOCR / PaddleOCR / Tesseract、matplotlib + 中文字体。
