# v4.0.0-dev.1 — W3 开发快照（预发布）

- 版本：**v4.0.0-dev.1**
- 发布日期：2026-11-05
- 发布类型：**Pre-release（开发快照，不是 Stable，不是 Alpha）**
- 契约集：`4.2.0`
- 产物 `schema_version`：`4.0`
- 对应提交：`293ebcf`（附注 tag `v4.0.0-dev.1`）
- 说明：这个 tag 上的 `engine.__version__` 仍是 `3.5.9`，到 v4.0.0 才正式改为 4.0.0。

## 一句话

这是 v4.0 执行链和 W3 加固的检查用快照，用来在正式稳定版之前确认主链、契约和审计修复都已经落地。

## 这个版本新增了什么

- **v4.0 执行链**：DocumentSpec 4.0 → ContentPlan / FillPlan → 事务执行器 + 填充台账 → QA 报告 4.0 → 提交门禁。
- **模板智能**：`--spec-version 4`、槽位 / 保护区域 / 容量模型、模板指纹、语义校验。
- **内容智能**：事实 `source` 溯源、SSOT 引用、容量冲突 `REJECT`、计划校验。
- **QA**：QA 报告 4.0、必需检查策略、QA 门禁、完整 Pipeline、运行时环境能力探测。
- **契约**：五份公共契约、CP-W2-001（页眉页脚位置语法）、CP-W2-002（`sdt` 位置语法与 PROTECTED 发现）。
- **W3 加固**：PDF 临时副本清理、Excel 三级公式状态、SDT fail-closed 披露、ZIP 输入配额、soffice 私有 profile。

## 这个版本修复了什么

- **W0 门禁**：COMMIT 与 UNVERIFIED 的矛盾、QA 策略来源可伪造。
- **W2**：合并单元格列索引、嵌套表格目标、图片替换残留占位文本、授权图片缩放指纹误报。
- **W3**：P1-01 SDT 静默漏检、P1-02 默认 GENERATE 走 v3 文档、P2-01 Excel 渲染器错误覆盖 builtin 状态、P2-02 PDF 源文件副本残留、P2-03 ZIP 资源限制缺失。
- **发布预检**：移除脚本中的本机绝对路径候选。

## 兼容性

- 契约 4.0.0 → 4.2.0 为 MINOR 加法：新增页眉 / 页脚位置语法和 `sdt` 位置语法；既有 `location_id` / `slot_id` 不变。
- CLI `--spec-version` 默认值仍为 3；v4 主链需要显式传 `--spec-version 4`。
- 旧 `--data` token 模式保留。
- SDT 内容会被发现和定位，但状态为 PROTECTED；`sdt_edit=false`，FillPlan 命中即 `PROTECTED_SLOT_VIOLATION`。

## 测试结果与环境

- **450 项通过**。
- 发布包解压后复跑：**450 项通过**（171.776s）。
- Windows / Python 3.15；WPS PDF 后端可用。

## 已知限制

- **不是 Alpha，也不是 W3 阶段完成**；W3 出口评审尚未执行。
- W3-9 真实模板语料仍待外部脱敏输入和人工标注；六类 Fixtures 是程序化构造的结构化回归样本，不是真实业务模板验证。
- P2-01 / P2-04 的最终关闭需要审计方 Linux / LibreOffice 完整套件复跑。
- 本机缺 PyMuPDF、matplotlib、OCR；相关检查如实 `UNVERIFIED`。
- 不支持 SDT 内填充。

## 安装 / 升级 / 回滚

1. 下载并解压 `officecli-template-filler-v4.0.0-dev-w3.zip`。
2. 将 `officecli-template-filler/` 放入 skills 目录。
3. 安装依赖：`python -m pip install -r requirements.txt`。
4. 回滚：删除该目录并恢复上一版本 skill 目录；本版本不修改用户模板或外部数据。
