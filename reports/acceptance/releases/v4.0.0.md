- 版本：**v4.0.0**
- 发布日期：2026-11-05
- 发布类型：**正式版**（发布时曾为 Latest，现由 v4.0.1 接替）
- 软件版本：`4.0.0`
- 契约集：`4.2.0`
- 产物 `schema_version`：`4.0`
- 对应提交：`c3cf9f2`（附注 tag `v4.0.0`）

## 一句话

这是 v4 架构的第一个稳定版，把文档处理做成一条可检查、可回滚的链路：先理解模板，再生成计划，执行时走事务，最后用检查和门禁决定能不能提交。

## 这个版本新增了什么

- **v4 文档主链**：`DocumentSpec 4.0 → ContentPlan / FillPlan → 事务执行器 + 填充台账 → QA 报告 → 提交门禁 → 原子提交`。
- **真实语料评测工具**：语料目录只在运行时通过 `--corpus` 传入，仓库不保存路径、文件名或文档内容；报告只含匿名序号、技术元数据和聚合指标。
- **46 份真实 `.docx` 验证**：解析 46/46、0 字节改动、0 个 Spec 校验失败；21 份可填模板全部完成填充并提交（12 PASSED、9 UNVERIFIED 因浮动图片覆盖缺口如实披露），模板字节 0 改动。
- **GENERATE 视觉检查使用 `STYLE_GUIDE` 档位**：内容变化引起的分页数、字体漂移按警告处理；页面几何、表格宽度等硬指标仍然阻断。

## 这个版本修复了什么

- 授权文本填充改为原位替换并保留被清空的 Run，不再重写 `rPr`；结构指纹只忽略被授权剥离的占位红色，消除真实模板的 `UNAUTHORIZED_TEMPLATE_CHANGE` 误报。
- `red_run_clue` / `internal_fact` 段落填充不再回退到 v3 strict-style 重建，字体、字号、加粗和段落标记保持不变。
- STANDARD 模式下 `UNVERIFIED` + 仅有覆盖缺口的报告按契约 04 §7 允许提交，`qa_eligible` 与 `final.eligible_for_commit` 不再矛盾。
- 模板自身已有的 `xml:space` 缺省、未被 FillPlan 触达的空位、模板既有红字降级为披露性警告；新引入的问题仍然阻断。
- 修复 `audit_format_and_text_qa(raise_on_failure=False)` 仍抛出包完整性异常的问题。
- Excel 超过 2 MB 的工作簿走只读扫描；图表 / 扩展解析异常回退只读并结构化披露，不再崩溃或长时间阻塞。

## 兼容性

- 软件版本从 3.5.9 跨到 4.0.0，用于标识 v4 文档主链；公共 API、v3.5.9 公共导出和 legacy 3.0 输出没有破坏。
- CLI `analyze_template.py --spec-version` 的默认值仍是 3；使用 v4 主链需要显式传 `--spec-version 4`。
- `UNVERIFIED` 报告的提交资格按契约 04 §7 处理：STANDARD + 显式允许即可提交，但缺失检查和覆盖缺口必须披露。

## 测试结果与环境

- 全量：**479 项通过**（Windows，Python 3.15，175.8s），无 failure / error / skip。
- 发布包解包复跑：**479 项通过**（173.4s）。
- 环境探测：`docx_parse`、`docx_write`、`wps_pdf_render`、`pdf_page_analysis` 可用；PyMuPDF、OCR、matplotlib 缺失。

## 已知限制

- 真实语料未经脱敏和人工标注，不计算、不声称槽位 P/R/F1。
- 不支持 SDT 内填充；SDT 只作为 PROTECTED 位置被发现并拒绝。
- 浮动图片、域更新、OLE、SmartArt、矢量图以 `UNSUPPORTED` / `UNVERIFIED` 披露。
- 含浮动图片的模板检查为 `UNVERIFIED`（可提交，但需要人工复核版式），不等于通过。
- Linux / LibreOffice 未验证。
- 独立 Agent 07 复查未在当前环境执行。
- 发布包里的 `SKILL.md` 目录树仍写 473 项测试，实际是 479 项；仓库后续已更正，tag 和发布资产未变。

## 安装 / 升级 / 回滚

- 安装：下载 `officecli-template-filler-v4.0.0.zip`，解压后将 `officecli-template-filler/` 放入 Agent 的 skills 目录。
- 升级：用本包替换旧版本目录；模板和产物格式未变更。
- 回滚：重新安装 v3.5.9 归档；v4 契约与旧 v3 输出仍由兼容门禁覆盖。
