# v4.0.1 — 稳定版补丁（Latest）

- 版本：**v4.0.1**
- 发布日期：2026-11-05
- 发布类型：**正式版（Latest stable）**
- 软件版本：`4.0.1`
- 契约集：`4.2.0`（不变）
- 产物 `schema_version`：`4.0`（不变）
- 对应提交：`2b5d41a`（附注 tag `v4.0.1`）

## 一句话

这是 v4.0.0 的合规补丁：移除了测试代码里残留的外部语料内容，统一了文档里的测试计数，并补齐了真实语料报告的可复现信息。

## 这个版本修复了什么

- **关闭独立审查阻断项 B1**：删除测试代码中残留的外部语料正文片段和来源归属措辞，回归语义改用完全合成的通用文本。仓库和发布包内不再出现语料路径、文件名或正文。
- 文档测试计数统一为 **479 项**（AGENTS / CHANGELOG / README / SKILL / engine reference）。
- 真实语料报告补充运行命令、参数、环境与时间；JSON 和报告增加 `coverage_gaps` / `missing_checks`，9 份 `UNVERIFIED` 的原因可以直接复核。

## 这个版本改变了什么

- `engine.__version__` 从 `4.0.0` 改为 `4.0.1`。
- 执行器 `data` 增加 `coverage_gaps` 自由字段，用于证据复核；ToolEnvelope 的 `data` 本来就是自由对象，不构成契约变更。
- 新增独立出口审查记录 `reports/w3/12-independent-exit-review.md`：v4.0.0 时裁定 FAIL，B1 由本补丁关闭。

## 破坏性变更

无。公共 API、契约、Schema、CLI 默认行为均未改变。

## 兼容性与支持范围

- 已验证平台：Windows + WPS PDF 后端；Windows + LibreOffice 26.8.2.2；Python 3.15。
- Linux 环境仍未验证。

## 测试结果与环境

- 工作树全量：**479 项通过**（173.0s）。
- 发布包解压后全量：**479 项通过**（171.6s）。
- LibreOffice 复验：定向 34 项通过（15.7s）；全量 479 项通过（182.1s）。
- 真实语料复跑：46/46 解析、21/21 填充提交、0 模板字节改动、12 PASSED / 9 UNVERIFIED（219.7s）。

## 已知限制

- **B2 部分关闭**：LibreOffice 26.8.2.2 已在 Windows 主机复验通过；Linux 环境仍不可用，P2-01 / P2-04 不能宣称完整关闭。
- v4.0.1 的独立复核待执行。
- 真实语料无人工标注基线，不计算、不声称槽位准确率。
- 不支持 SDT 内填充；浮动图片检查为 `UNVERIFIED`；域更新 / OLE / SmartArt / 矢量图以 `UNSUPPORTED` 或 `UNVERIFIED` 披露。
- 本机缺 PyMuPDF / matplotlib / OCR，相关可选检查如实 `UNVERIFIED`。

## 安装 / 升级 / 回滚

- 安装 / 升级：用本包替换旧版本 Skill 目录；模板和产物格式未变更。
- 回滚：可以继续使用 v4.0.0 归档；本补丁只涉及测试文本、文档计数和证据字段。
