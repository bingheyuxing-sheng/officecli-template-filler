## 一句话

在修改模板之前，先让系统真正“看懂”模板：分析结构、标记需要填写的位置，并把无法确定的内容交给用户确认；没有确认记录就不允许生成、修复、重排或审阅。

## 这个版本新增了什么

- **模板理解与确认闸门**：把模板证据分成已确认、待确认、有歧义、有冲突四类，并绑定到确认记录。
- **确认记录**：记录模板 SHA-256、DocumentSpec 摘要、模板指纹、证据摘要、任务类型、用户确认内容和有效期。
- **执行入口强制校验**：`GENERATE / REPAIR / REFORMAT / REVIEW` 没有有效确认记录时停止，不再继续写入。
- **确认记录失效**：模板被修改、任务类型变化、记录被篡改时，返回 `TEMPLATE_GATE_STALE` 或 `TEMPLATE_GATE_CONFIRMATION_REQUIRED`。
- **CLI**：`scripts/template_gate.py` 提供 analyze / report / resolve / confirm / reject / status 子命令。
- **错误码**：新增 7 个闸门错误码，包括 `TEMPLATE_GATE_REQUIRED`、`TEMPLATE_GATE_BLOCKED`、`TEMPLATE_GATE_STALE`、`TEMPLATE_EVIDENCE_CONFLICT` 等。

## 这个版本改变了什么

- 生成、修复、重排、审阅四类任务在无确认记录时不再执行；这是 W4 的预期行为变化。
- `PROOFREAD / EXCEL_GENERATE / POLISH / MERGE / RENDER` 保持原有行为。
- `SKILL.md` 新增 Step 1.5 模板理解闸门工作流。
- `analyze_template.py --spec-version` 的默认值仍为 3，兼容边界不变。

## 安装 / 升级

1. 下载 `officecli-template-filler-v4.1.0.zip`。
2. 解压到 Agent 的 skills 目录，或作为普通 Python 项目使用。
3. 安装依赖：`python -m pip install -r requirements.txt`。
4. 已有工作流需要增加模板分析、确认和 `--gate-record` 步骤；不增加会按闸门规则停止。
