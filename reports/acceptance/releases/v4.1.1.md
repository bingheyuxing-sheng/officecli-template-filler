## 一句话

## 这个版本改变了什么

- `SKILL.md` 的 frontmatter description 从 900 多字符压缩到 376 字符，更容易被正确触发。
- 主文件顶部改为“四步启动检查 + Operating contract + Resource map”。
- 补充模板理解闸门的可见性和 CLI 命令表。
- 新增 `references/workflow-details.md`，承接事务提交、检查点、渲染 / 目录降级、QA 报告语义和内容检查代码表。
- `README.md`、`SKILL.md`、`references/python-docx-engine.md` 的版本行同步到 v4.1.1。

## 兼容性

- 无运行时行为变化。
- 无契约、Schema、错误码变化。
- 契约集保持 `4.3.0`；`schema_version` 保持 `4.0`。
- 模板理解闸门的行为与 v4.1.0 相同。
