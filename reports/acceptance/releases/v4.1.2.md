- Release：https://github.com/bingheyuxing-sheng/officecli-template-filler/releases/tag/v4.1.2

## 一句话

审阅文档时，Excel / JSON 里的检查结果现在可以直接写成目标 Word 文档里的批注，不需要再单独交付一份“核查报告”。

## 这个版本新增了什么

- `review_document.py --findings findings.json`：把外部 findings 转成目标正文或表格里的批注。
- 支持批注和文本修订同时使用：文字改动仍然写成 Word 修订，判断类问题写成批注。
- 无法定位的 finding 返回 `COMMENT_LOCATION_UNRESOLVED`，不会静默丢弃。
- 新增 `build_findings_review_plan()`，校验 `body.p[n]` / `body.tbl[t].r[r].c[c]` 位置。

## 这个版本改变了什么

- `SKILL.md` 与 `references/engine-internals.md` 明确：REVIEW 的交付物必须是目标方案正文的 `.docx`，不再输出独立的“核查报告” `.docx`。
- `review_report.json` 仍作为旁路审计文件保留，供需要时复核。

## 兼容性

- 不修改冻结契约、Schema 或错误码语义。
- 原有 `review_document.py` 用法不受影响；不传 `--findings` 时行为不变。
- 契约集保持 `4.3.0`；`schema_version` 保持 `4.0`。

## 测试结果

- 全量：**535 项通过**（发布包记录 191.921s）。
- 契约：**72 项通过**。

## 已知限制

- W4 独立出口审查仍未完成；本版本是稳定版候选，不是正式稳定版 PASS。
- 未在 W4 链路重跑 46 份真实语料；真实语料结果属于 v4.0.0。
- 不支持 Word 内容控件（SDT）内部填充。
- 浮动图片、域更新、OLE、SmartArt、矢量图仍以 `UNSUPPORTED` / `UNVERIFIED` 披露。
- 本机缺 PyMuPDF / matplotlib / OCR，相关可选检查如实标为 `UNVERIFIED`。

## 安装 / 升级

1. 下载 `officecli-template-filler-v4.1.2.zip`。
2. 解压到 Agent 的 skills 目录，或作为普通 Python 项目使用。
3. 安装依赖：`python -m pip install -r requirements.txt`。
4. 已有命令和模板格式不需要修改；如果使用旧 Skill 副本，请替换为 v4.1.2。
